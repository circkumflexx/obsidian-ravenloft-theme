# Changelog

All notable changes to Ravenloft are documented in this file. Releases are listed in reverse chronological order and use [Semantic Versioning](https://semver.org/).

## 2.0.1 — The Mists Are Still Here

### Added

- Embedded the genuine Vollkorn SC SemiBold (600) and Bold (700) font files, including their Cyrillic glyphs.
- Added this changelog and a separate [AI assistance disclosure](AI-DISCLOSURE.md).

### Changed

- Retuned the existing Literata body text for long-form reading: the default size is now 17 px instead of 16 px, while the 1.65 line height remains unchanged.
- Reduced the default readable line width from 740 px to 680 px to improve the density and colour of the page.
- Increased heading weights to 700 for H1–H2 and 600 for H3–H6, using genuine Vollkorn SC font files rather than synthetic browser bolding.
- Updated release metadata to version 2.0.1.
- Revised the README for clarity and moved release history into this file.

## 2.0.0 — The Mists Are Still Here

### Added

- Added bilingual Style Settings controls.
- Added Focus, density, atmosphere, contrast, and reduced-motion controls.
- Added custom `mist` and `lore` callouts.
- Added native Bases, Properties, tabs, navigation, modal, mobile, and print coverage.

### Changed

- Rebuilt the theme around modern Obsidian CSS variables.
- Redesigned the Light and Dark semantic palettes.
- Updated CodeMirror 6 and search styling.
- Improved contrast and maintainability while preserving all original embedded typefaces.

## 1.1.1 — The Bound Font Edition

### Added

- Embedded the original font stack directly in `theme.css`.

### Fixed

- Corrected documentation details.
