# Font licences and attribution

Ravenloft embeds the following unmodified font binaries in `theme.css` so that
the theme works without runtime network requests. Each font is distributed
under the **SIL Open Font License, Version 1.1 (OFL-1.1)**. The copyright and
licence records are also retained in the embedded TTF metadata.
